# MIPT_practice

Этот репозиторий — рабочая папка для учебных и исследовательских материалов в рамках практики МФТИ.
Здесь собраны домашние задания, экзаменационные работы и отдельный исследовательский эксперимент.

## Структура репозитория

### `homework/`
Домашние задания по разным предметам и семестрам: Python, основы машинного обучения,
визуализации, цифровая кафедра и другие. Каждое задание лежит в своей подпапке.
Внутри обычно ноутбук с решением и, при необходимости, исходные данные или вспомогательные файлы.
Подробный список со ссылками на конкретные работы — в `homework/README.md`.

### `exams/`
Экзаменационные ноутбуки и работы по семестрам: Python, математика для машинного обучения,
инжиниринг данных, глубокое обучение. Список файлов — в `exams/README.md`.

### `experiment/`
Отдельный исследовательский эксперимент по теме «гибридное отслеживание сюжетов новостей»
(hybrid story tracking). Здесь лежит публичная версия кода и итоговые числовые результаты,
которые можно показать без приватных данных. В этой папке:

- `src/` — основная логика: сборка набора данных, расчёт метрик, оценка моделей, построение графиков;
- `tools/` — служебные сценарии для пересчёта и проверки результатов;
- `configs/` — пример конфигурации эксперимента (без секретов);
- `docs/` — описание замысла эксперимента, гипотез и методики оценки;
- `results/` — итоговые таблицы метрик в формате CSV/JSON.

Подробности — в `experiment/README.md`.

## Что не входит в репозиторий

В репозитории намеренно нет приватных текстов сообщений, дампов баз данных, ключей доступа,
больших векторных представлений и внутренних расчётных конвейеров. В публичной версии оставлены
только итоговые агрегированные числа, описание методики и сам код оценки.
