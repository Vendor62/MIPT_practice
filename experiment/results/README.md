# `results/` — итоговые числовые результаты

В этой папке лежат итоговые сводки по эксперименту в формате CSV и JSON.
Это та часть, которую можно показать без приватных текстов и без дампов
данных: только агрегированные числа.

## Файлы верхнего уровня

- `dataset_summary.json` — краткая сводка по набору данных: общее число постов,
  число размеченных историй, разбивка на одиночные и многопостовые истории.
- `final_metrics_summary.csv` — итоговая таблица метрик по методам
  (semantic-only, гибридный, LLM-судья) на тестовой подвыборке.
  Используется в `src/plotting.py` для построения графиков.
- `llm_baseline_summary.csv` — отдельная сводка по LLM-судье (DeepSeek Chat):
  основные метрики качества кластеризации.

## Подпапки

- `commission_audit_v2/` — расширенные таблицы для повторной проверки итоговых
  чисел (commission audit v2): метрики по методам и подгруппам, доверительные
  интервалы по бутстрэпу, статусы основных гипотез, сравнение с прошлой
  версией. Подробности — в `commission_audit_v2/README.md`.

## Чего здесь нет

- Картинок (`.png`) нет: их можно сгенерировать локально через
  `python src/plotting.py`.
- Размеченных текстов, идентификаторов авторов и других чувствительных полей
  нет — только агрегированные числа.
