# Эксперимент: гибридное отслеживание сюжетов (hybrid story tracking)

Эта папка содержит компактную публичную версию кода эксперимента по оценке гибридного
отслеживания сюжетов в задаче объединения новостных сообщений Telegram в общие истории.

В эксперименте сравниваются три подхода:
- **semantic-only** — базовое решение только по смысловой близости текстов (embeddings);
- **hybrid_v4_1_soft_entity_penalty** — гибридный счёт: смысловая близость + время публикации
  + сигналы по сущностям/графу + защита от лишних склеек историй;
- **deepseek_chat_llm** — внешний LLM в роли судьи: для каждого нового поста модель
  выбирает либо приклеить его к одной из похожих историй, либо завести новую историю.

В публичный репозиторий **не** включены приватные тексты сообщений Telegram, дампы баз
данных, ключи доступа и внутренний промышленный расчёт графовых признаков. Оставлены
только протокол оценки, реализация метрик, пример конфигурации, итоговые числовые
результаты и сценарий построения графиков.

## Итоговый набор данных (manual gold)

- 657 постов;
- 300 размеченных историй;
- 180 историй из одного поста (singleton);
- 120 историй из нескольких постов (non-singleton).

## Главный результат

Сравнение гибридного подхода и базового «только по смыслу» на сводном размеченном наборе:

| Метод | Pairwise F1 | ARI | NMI | FMR | FSR |
|---|---:|---:|---:|---:|---:|
| Semantic-only | 0.121 | 0.106 | 0.792 | 0.078 | 0.556 |
| Hybrid | 0.269 | 0.259 | 0.876 | 0.021 | 0.500 |
| DeepSeek Chat | 0.295 | 0.285 | 0.871 | 0.022 | 0.481 |

Гибридный подход улучшает базовый «только по смыслу»:
- +14.77 п.п. по Pairwise F1;
- +15.24 п.п. по ARI;
- +8.45 п.п. по NMI.

## Про воспроизводимость

Код в этой папке — это очищенная публичная версия. Исходный эксперимент опирался на
приватные источники данных в PostgreSQL и Neo4j, а также на внутренний промышленный
расчёт графовых признаков. Чувствительные данные и ключи доступа намеренно исключены.
Поэтому полностью «с нуля» воспроизвести числа из таблицы по публичной версии нельзя —
сохранены метод, протокол оценки и итоговые таблицы.

## Что лежит в подпапках

- `src/` — основная логика эксперимента: сборка набора данных, расчёт парных признаков,
  оценка модели, метрики и построение графиков. Подробности — в `src/README.md`.
- `tools/` — служебные сценарии для пересчёта итоговых метрик и проверочных прогонов
  (commission audit v2). Подробности — в `tools/README.md`.
- `configs/` — пример конфигурации эксперимента без секретов. Подробности — в
  `configs/README.md`.
- `docs/` — описание замысла эксперимента, гипотез и методических заметок.
  Подробности — в `docs/README.md`.
- `results/` — итоговые таблицы метрик и сводки по набору данных. Подробности — в
  `results/README.md`.

## Быстрый старт (только построение графиков)

Файлы `.png` в репозиторий не включены, их можно собрать локально:

```bash
cd experiment
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/plotting.py
```
