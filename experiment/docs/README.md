# `docs/` — описание замысла и методики

Текстовые материалы по эксперименту: что проверяем, как устроен набор данных,
какие метрики важны и почему именно они.

## Файлы

- `experiment_design.md` — общий замысел: основная гипотеза, какие подходы
  сравниваем (semantic-only, гибридный, внешний LLM), как устроен размеченный
  набор данных, как делим его на части (train/dev/test), какие метрики
  используем и как устроен LLM-протокол.
- `methodology_notes.md` — методические заметки: почему не оптимизируем
  простую точность по постам, как устроены ограничения против лишних склеек,
  как разводятся идентификаторы историй между двумя источниками разметки,
  почему размеченные метки никогда не подаются в само решение.
