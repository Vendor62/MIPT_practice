# `configs/` — примеры конфигурации

В этой папке лежит пример конфигурации эксперимента. Это шаблон без секретов и
без путей к приватным данным — его можно скопировать и адаптировать под локальный
запуск.

## Файлы

- `experiment_config.example.yaml` — пример сквозной конфигурации:
  - название набора данных;
  - условные пути до файлов с метками, разбиением и парными признаками;
  - параметры оценки: хронологический порядок, доли train/dev/test, список
    сравниваемых методов, ограничения при подборе порога;
  - параметры внешнего LLM-судьи: какие переменные окружения читать, размер
    списка кандидатов и ограничение длины промпта.

## Что не входит

- Никаких ключей доступа и токенов в файлах конфигурации **нет** и быть не должно.
  Все чувствительные значения берутся из переменных окружения по именам,
  указанным в конфигурации (например, `DEEPSEEK_API_KEY`).
- Реальные пути к приватным данным (`./data/private/...`) — это шаблон, эти
  файлы в публичный репозиторий не входят.
